# **TABBED INVENTORY UPDATE BUG - ROOT CAUSE ANALYSIS**

## **1. ROOT CAUSE(S) WITH FILE:LINE REFERENCES**

### **Primary Root Cause: ItemHelpers Missing Tabbed Container Check**

**File**: `src/ClassicUO.Client/Network/PacketHandlers/Helpers/ItemHelpers.cs:117-119`

```csharp
GridContainer gridGump = UIManager.GetGump<GridContainer>(containerSerial);
if (gridGump != null)
    gridGump.RequestUpdateContents();
```

**The Problem:**
- Assumes container is always a separate GridContainer window
- **Tabbed containers are NOT separate Gumps**—they're internal tabs within a parent GridContainer
- `UIManager.GetGump<GridContainer>(tabContainerSerial)` returns `NULL` for tabs
- When NULL, the update silently fails → tab shows stale data until manually switched

### **Secondary Issue: Code Path Divergence from OpenContainer**

**File**: `src/ClassicUO.Client/Network/PacketHandlers/OpenContainer.cs:221-224`

OpenContainer **correctly** handles tabbed containers:
```csharp
GridContainer parentGC = GridContainer.FindParentGridContainer(world, serial);
if (parentGC != null && parentGC.HasTab(serial))
{
    parentGC.RequestUpdateContentsForTab(serial);
}
```

**File**: `src/ClassicUO.Client/Game/UI/Gumps/GridContainer.cs:1455-1465`

A proper helper method exists but is unused:
```csharp
internal static void NotifyContainerUpdate(World world, uint containerSerial)
{
    GridContainer gc = UIManager.GetGump<GridContainer>(containerSerial);
    if (gc != null)
    {
        gc.RequestUpdateContents();
        return;
    }
    GridContainer parent = FindParentGridContainer(world, containerSerial);
    parent?.RequestUpdateContentsForTab(containerSerial);
}
```

**Status**: This method only called from OpenContainer, NOT from ItemHelpers.

### **Tertiary Issue: Inactive Tab Cache Never Invalidated**

**File**: `src/ClassicUO.Client/Game/UI/Gumps/GridContainer.cs:1481-1495`

When RequestUpdateContentsForTab is called on an **inactive tab**, it immediately rebuilds:

**But** since ItemHelpers never calls RequestUpdateContentsForTab, this rebuild never happens.

### **Why ItemHelpers Path Fails**

**Location of items in memory:**
- Direct containers: `_parentGridContainer = null` → separate Gump registered in UIManager
- Tabbed containers: `_parentGridContainer = parentGC` → NO separate Gump, stored in `parentGC._tabs` array

**UIManager.GetGump<GridContainer>(serial)** only finds gumps registered in UIManager, not internal tab objects.
